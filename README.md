# Bản sao giao diện SoICT

Đây là bản dựng lại giao diện website SoICT theo , mô phỏng bố cục, điều hướng, các trang nội dung, hiệu ứngl, danh sách tin tức, sự kiện, giảng viên và một số thành phần tương tác.

## Công nghệ sử dụng

- React
- Vite
- JavaScript
- CSS

Không sử dụng backend, cơ sở dữ liệu hay API server.
